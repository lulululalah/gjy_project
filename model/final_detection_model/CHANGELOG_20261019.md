# 单三分类头第二轮优化记录

本轮目标：保持一个共享编码器和一个三分类头，争取同时达到旧双头的铆钉 F1 与饰面 F1。

## 修改与预设实验

- 三分类头隐藏层由 96 增至 192；仍为一个 MLP 和一个三路输出层，softmax 后取最大概率类别。
- 旧双头只在 17 架训练数据上提供辅助监督；训练时同时使用真实标签，推理不载入旧双头，也不合并二分类预测。
- 教师三路辅助 logits 为 [0, rivet_logit-logit(0.9), surface_logit-logit(0.5)]，温度 T=2，蒸馏 KL 权重 1、真实标签损失权重 0.5。
- 这是带校准偏移的教师分数近似，不等价于原双头铆钉优先规则的精确重参数化。
- 两组均固定 seed=123、200 轮：全程冻结编码器；以及冻结 40 轮后以初始 lr=0.00002 微调。头 lr=0.001、余弦衰减、dropout=0.1。
- 数据、真值、输入归一化、几何补全和后处理保持一致；全九架统一评估，不单列某架作为优化目标。
- 预先规定：两类 F1 均不低于当前三分类且均值提高才可替换；符合者按均值最高、误报更少选择。

该固定测试集已用于开发，本轮结果和候选选择不能作为未见数据的独立泛化验证。没有按测试集挑轮数、阈值或中间 checkpoint。
