# AAGNet 借鉴与模型改进方案

日期：2026-09-04

## 1. 目标

当前模型需要同时满足以下业务要求：

1. 铆钉允许少量漏检，但应尽量避免误检。
2. 贴花、原生贴花和原生窗户统一识别为 `surface_feature`。
3. `surface_feature` 可以存在一定漏检和误检，但召回率目标至少为 50%。
4. 不允许把机身、机翼等大面积背景面大范围预测为 `surface_feature`。
5. 铆钉与 `surface_feature` 使用完全独立的 specialist 编码器，分别训练和校准，最后合并输出。

## 2. 当前结果与问题

Fold1 的 50 轮对照训练使用了以下配置：

- surface 正类权重：4 倍
- focal gamma：1
- 铆钉阈值：0.9
- surface 阈值：0.5
- 模型结构：独立的 rivet specialist 和 surface specialist

默认阈值下的结果：

| 指标 | 结果 |
| --- | ---: |
| 铆钉 TP / support | 188 / 188 |
| 铆钉 recall | 100% |
| 铆钉 FP | 8 |
| surface TP / support | 185 / 832 |
| surface recall | 22.24% |
| surface FP | 650 |
| 最大背景误检归一化面积 | 0.753660 |

通过降低 surface 阈值可以达到 50% recall：

| 参数或指标 | 结果 |
| --- | ---: |
| rivet threshold | 0.9802 |
| surface threshold | 0.1288 |
| 铆钉 recall | 89.36% |
| 铆钉 FP | 0 |
| surface recall | 50.36% |
| surface FP | 1581 |
| 面积不小于 0.01 的背景误检 | 8 |
| 面积不小于 0.05 的背景误检 | 4 |
| 最大背景误检归一化面积 | 0.753660 |

这说明当前问题不只是阈值设置。模型对真实 surface 和背景的概率排序仍然重叠，单纯降低阈值虽然能够提高召回率，却会造成大量背景误检。

## 3. 已经从 AAGNet 借鉴的部分

当前代码已经加入以下 AAGNet 风格设计：

- 面特征和边特征分别经过输入编码器。
- 输入编码器使用 `Linear + LayerNorm + ReLU`。
- GNN 层使用残差连接。
- 使用 LayerNorm，减少小批次训练时 BatchNorm 的不稳定性。
- 深层编码器拼接面级局部特征和整架飞机的全局 mean/max pooling 特征。
- rivet 和 surface 使用两个完全独立的编码器，避免两个任务共享表示时互相干扰。

这些修改提升了模型结构的稳定性，但还没有引入 AAGNet 最重要的动态边更新、PNA 聚合和实例关系监督。

## 4. 可继续借鉴的 AAGNet 方案

### 4.1 动态边特征更新

AAGNet 的 `EdgeMPNN` 会使用边两端面的特征更新边表示。当前模型的边特征主要来自预先导出的静态属性，训练过程中不会根据相邻面的语义重新编码。

建议在 surface specialist 中增加：

```text
edge_new = EdgeMLP(edge_old, source_face, target_face)
```

重点表达以下关系：

- surface 面与宿主机身面的附着关系；
- 字母内外面之间的几何关系；
- 普通机身分割边与贴花轮廓边之间的区别；
- 大面积宿主面和附着小面的角色差异。

预期作用：提高真实 surface 的可分性，同时降低大面积背景误检。

### 4.2 PNA 风格的 sum/max 邻域聚合

AAGNet 的 NodeMPNN 同时采用 `sum` 和 `max` 聚合。当前 NNConv 的单一聚合可能让关键的小贴花边界信号被大量普通邻居稀释。

建议 surface specialist 至少融合：

```text
neighbor_sum
neighbor_max
neighbor_mean
node_degree
```

其中：

- `max` 保留最明显的附着边或几何异常；
- `sum` 表达邻接结构总量；
- `mean` 表达平均邻域状态；
- `degree` 帮助区分机身主体面和小型附着面。

预期作用：首先改善 surface recall，并减少模型仅凭单个面属性作出判断。

### 4.3 局部、宿主区域和整机全局特征融合

AAGNet 在分类前拼接局部面表示与零件全局表示。当前模型已经加入整机 mean/max pooling，但仍缺少贴花所在宿主区域的中尺度表示。

建议 surface 分类头使用：

```text
当前面表示
+ k-hop 邻域表示
+ 宿主连通区域表示
+ 整架飞机全局表示
```

预期作用：让模型判断一个面在整架飞机中的角色，从而识别机身、机翼等主体背景面。

### 4.4 surface 实例关系辅助头

AAGNet 同时预测语义类别和面之间的实例关系。这个设计可以用于解决字母内外面、几何重合面标签和预测不一致的问题。

建议在 surface specialist 上增加关系头：

```text
surface_head(face) -> 是否为 surface_feature
relation_head(face_i, face_j) -> 是否属于同一个 surface 实例
```

关系标签可以自动从以下信息构造：

- 邻接面；
- 已生成的几何重合组；
- 同一连通 surface 区域；
- 已确认的 surface 标签传播结果。

当字母外面被确认或高置信度预测为 surface，关系头可以推动对应内面得到一致预测，不需要逐个模型人工确认。

预期作用：提高字母、窗框和复合贴花的完整率，并抑制孤立、无结构的背景误检。

### 4.5 UV 面网格与边网格编码

AAGNet 会对面的 UV 网格和边上的采样点进行卷积编码。当前模型主要使用面积、曲率、曲面类型和邻接统计等标量特征；当背景面与贴花面的统计值相似时，这些特征不足以表达字母轮廓和局部几何变化。

加入 UV 几何编码需要修改 STEP 特征导出、数据格式和训练加载流程，因此放在后续阶段。

预期作用：这是区分复杂贴花轮廓和机身背景最有潜力的方案，但开发成本也最高。

## 5. 修改优先级

| 优先级 | 修改项 | 目标 | 当前状态 | 是否解决 |
| --- | --- | --- | --- | --- |
| P0 | surface specialist 动态边更新 | 学习 surface 与宿主面之间的附着关系 | 未实现 | 否 |
| P0 | sum/max/mean 多聚合 | 保留关键邻接信号，提高 surface recall | 未实现 | 否 |
| P1 | surface 实例关系辅助头 | 统一字母内外面及几何重合面的预测 | 未实现 | 否 |
| P1 | 宿主区域 pooling | 识别机身、机翼等主体背景 | 未实现 | 否 |
| P1 | 自动生成关系训练标签 | 避免逐个模型人工确认内外面 | 已有几何分组基础，尚未接入训练 | 部分解决 |
| P2 | 面积分层 hard negative 训练 | 加强大背景负样本监督 | 已实现基础版本 | 部分解决 |
| P2 | 分别校准 rivet/surface 阈值 | 保证铆钉零误检并控制 surface recall | 已实现 | 部分解决 |
| P3 | UV 面/边网格编码 | 学习真实轮廓、法向和曲面分布 | 未实现 | 否 |

## 6. 推荐实施顺序

### 阶段一：不改变数据格式

1. 保持 rivet specialist 和现有铆钉模型不变。
2. 在 surface specialist 内实现动态 EdgeMPNN。
3. 将 surface 的 NNConv 聚合替换或扩展为 sum/max/mean 多聚合。
4. 仅在 Fold1 上进行短周期对照训练。
5. 达到改善后，再运行四折完整训练。

### 阶段二：加入关系监督

1. 利用几何重合组、邻接关系和 surface 标签生成面关系标签。
2. 增加 surface relation head 和辅助 BCE loss。
3. 推理时对高置信关系组执行一致性融合，而不是简单按面积过滤。
4. 检查字母内外面、窗框以及多面贴花的完整率。

### 阶段三：增加 UV 几何输入

仅在阶段一和阶段二仍无法同时满足 recall 与背景误检目标时实施：

1. 从 STEP 面均匀采样 UV 点、法向和有效区域掩码。
2. 从共享边采样坐标、切向和二面角。
3. 分别增加 face-grid encoder 和 edge-grid encoder。
4. 将网格编码与现有标量特征融合。

## 7. 验收标准

任何新模型不能只依据总 F1 判断。每个 Fold 和每架飞机都必须报告：

- 铆钉 TP、FP、FN、precision 和 recall；
- surface TP、FP、FN、precision、recall 和 F1；
- background-to-surface FP 数量；
- 最大 background-to-surface 误检面积；
- 面积不小于 0.01 和 0.05 的背景误检数量；
- 典型飞机的真值/预测叠加可视化。

阶段一模型的最低晋级条件：

```text
rivet FP = 0 或接近 0
surface recall >= 50%
不存在机身、机翼级别的大面积背景误检
相比当前 Fold1 的 surface FP=1581 明显下降
```

不能采用固定面积上限直接删除 surface 预测，因为真实贴花和窗户也可能具有较大面积。面积只能用于负样本采样、损失加权和审计，最终判断仍应主要依赖几何、拓扑和上下文关系。

## 8. 结论

AAGNet 中最适合当前任务的不是单编码器或普通分类头，而是以下三项组合：

1. 动态边消息传递；
2. sum/max 多尺度邻域聚合；
3. surface 实例关系辅助监督。

这些结构应只移植到独立的 surface specialist，铆钉 specialist 保持独立。这样既能继续控制铆钉误检，也能针对 surface recall 低、字母内外面不一致和大背景误检三个核心问题进行改进。
