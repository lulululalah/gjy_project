# 2026-08-12：inner loop BFS 拓扑特征

## 当前结论

此前对“一个 inner loop 内只有 1–2 个面”的理解有误：原实现使用的是宿主面自身的 inner loop 数量（`hasOneOrTwoInnerLoops`），这并不能描述某个具体 inner loop 内部的拓扑规模。该错误实现及基于它得到的全部实验结果均已废弃。

当前实现采用正确的定义：对每个 inner loop，从其边界边另一侧的相邻面开始，将这些面记为 BFS 第 1 层；随后沿面邻接关系向内部遍历。遍历时不允许跨越该 loop 的边界边，也不允许返回宿主面。只有该内部可达区域的最大 BFS 深度不超过 2 时，该 loop 才满足条件。

## 今天完成的修改

### 特征提取

已在 `FeatureExtractor` 与 CSV 导出中加入以下 inner-loop 特征：

- `minInnerLoopBoundaryDihedralMax`：宿主面的所有有效 inner loop 中，边界采样二面角最大值的最小值。
- `minInnerLoopBoundaryRightAngleDeviation`：所有有效 loop 中，边界采样二面角相对 90 度最大偏差的最小值。
- `hasValidInnerLoopBoundaryDihedral`：区分有效几何测量值与 `-1` 哨兵值。
- `innerLoopAllDihedralBelowThreshold`：至少一个 loop 的全部边界采样二面角均小于 15 度。
- `hasInnerLoopInteriorBfsDepthAtMost2`：至少一个 loop 的内部完整 BFS 最大深度不超过 2。
- `hasSmallFlatInnerLoop`：同一个 loop 同时满足 BFS 深度不超过 2 与平坦边界条件。
- `hasSmallRightAngleInnerLoop`：同一个 loop 同时满足 BFS 深度不超过 2 与最大直角偏差小于 15 度条件。

此前的绝对面积标记 `isSmallAbsoluteAreaFace` 已删除：开发折消融结果显示它没有带来有意义的整体 F1 提升。此前的宿主面 inner loop 数量标记已替换为上述 BFS 特征。

### 训练脚本集成

`python/train_rivet_gcn.py` 已支持这 7 个新列，通过 `--use-inner-loop-features` 显式启用。该开关默认关闭，因此旧 CSV 和当前基线行为不变；只有使用新导出的 CSV 且主动传入该参数时，才会使用这些特征。
