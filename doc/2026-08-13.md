## 网络问题与处理

下载初始失败的原因是当前进程环境中的三个代理变量均指向未监听的本机端口：

```text
ALL_PROXY=http://127.0.0.1:9
HTTP_PROXY=http://127.0.0.1:9
HTTPS_PROXY=http://127.0.0.1:9
```

Git 与 pip 因此无法连接。仅在单次 pip 子进程中临时移除了这三个变量后，`build123d` 依赖成功下载到 AeroShape 私有 `vendor` 目录。没有修改 Windows 系统代理、用户环境变量或 Conda 环境。
