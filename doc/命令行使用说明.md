# 命令行使用说明

本文档只保留当前仍在使用的图方法流程。

建议所有命令都在项目根目录执行：

```powershell
cd D:\Projects\gjy_byproject
```

## 1. 导出图训练集

作用：
- 遍历 `data/dirty_training_set` 下的 STEP 模型
- 提取 face-level 几何与拓扑特征
- 导出图神经网络训练所需的 CSV

命令：

```powershell
.\build\Debug\Detector.exe --train
```

输出文件：
- `data/full_training_set.csv`

## 2. 训练图神经网络

作用：
- 读取 `data/full_training_set.csv`
- 按 `graph_id` 组装图数据
- 训练当前使用的 `RivetGNN`

命令：

```powershell
python .\python\train_rivet_gcn.py
```

常用带参版本：

```powershell
python .\python\train_rivet_gcn.py --csv data/full_training_set.csv --epochs 150 --batch-size 8 --hidden-dim 64 --lr 0.001
```

输出文件：
- `rivet_gnn.pth`
- `rivet_gnn_stats.npz`

## 3. 导出单模型推理数据

作用：
- 对单个 STEP 模型提取 face-level 图特征
- 生成推理阶段使用的 CSV

命令：

```powershell
.\build\Debug\Detector.exe --predict .\data\dirty_training_set\44.step
```

输出文件：
- `data/current_inference.csv`

## 4. 可视化 GNN 预测结果

作用：
- 调用 `Detector.exe --predict`
- 加载 `RivetGNN` 模型做推理
- 按面标签对 STEP 模型着色显示

命令：

```powershell
conda activate cad_graph_env
cd D:\Projects\gjy_byproject
python .\python\visualize_rivets.py .\data\dirty_training_set\44.step --detector .\build\Debug\Detector.exe
```

常用参数：

```powershell
python .\python\visualize_rivets.py .\data\dirty_training_set\44.step --detector .\build\Debug\Detector.exe --hidden-dim 64
```

## 5. 推荐流程

建议按下面顺序执行：

1. 把训练 STEP 模型放进 `data/dirty_training_set`
2. 运行 `Detector.exe --train` 导出训练 CSV
3. 运行 `python .\python\train_rivet_gcn.py` 训练模型
4. 运行 `Detector.exe --predict <file>` 或 `python .\python\visualize_rivets.py <file>` 做推理验证

## 6. 常见问题

### 6.1 找不到 `python\visualize_rivets.py`

先确认当前目录在项目根目录：

```powershell
cd D:\Projects\gjy_byproject
```

### 6.2 `ModuleNotFoundError: No module named 'OCC'`

说明当前 Python 环境没有 `pythonocc`，先切到可视化环境：

```powershell
conda activate cad_graph_env
```

### 6.3 推理 CSV 缺少 `graph_id` 或 `model_name`

这通常说明用了旧 CSV，重新执行一次：

```powershell
.\build\Debug\Detector.exe --predict .\data\dirty_training_set\44.step
```
