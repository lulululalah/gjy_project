 # 命令行使用说明

本文整理当前项目从训练到推理、可视化验证的常用命令。

建议所有命令都在项目根目录执行：

```powershell
cd D:\Projects\gjy_byproject
```

## 1. 生成孔洞候选训练集

作用：
- 遍历 `data/dirty_training_set` 下的 STEP 模型
- 提取 `FaceFeature`
- 构造 `HoleCandidate`
- 导出训练 CSV

命令：

```powershell
.\build\Debug\Detector.exe --train-hole
```

输出文件：
- `data/hole_candidate_training_set.csv`

## 2. 生成 face-level 训练集

作用：
- 导出旧的 face-level 训练数据
- 主要用于原型路线，不是当前孔洞主线

命令：

```powershell
.\build\Debug\Detector.exe --train
```

输出文件：
- `data/full_training_set.csv`

## 3. 训练孔洞候选模型

作用：
- 读取 `data/hole_candidate_training_set.csv`
- 训练当前的 `HoleCandidateMLP`
- 输出模型权重和归一化参数

命令：

```powershell
python .\python\train_hole_candidate_gcn.py
```

常用带参数版本：

```powershell
python .\python\train_hole_candidate_gcn.py --csv data/hole_candidate_training_set.csv --epochs 150 --batch-size 64 --hidden-dim 64 --lr 0.001
```

输出文件：
- `hole_candidate_mlp.pth`
- `hole_candidate_stats.npz`

## 4. 对单个模型做文本推理

作用：
- 先导出当前 STEP 的孔洞候选
- 再用训练好的模型打分
- 在终端打印预测分布和高分候选

命令示例：

```powershell
python .\python\predict_hole_candidates.py .\data\dirty_training_set\44.step --detector .\build\Debug\Detector.exe
```

常用参数：
- `--top-k 20`
- `--top-negative-k 10`

示例：

```powershell
python .\python\predict_hole_candidates.py .\data\dirty_training_set\44.step --detector .\build\Debug\Detector.exe --top-k 30
```

中间输出文件：
- `data/current_hole_candidates.csv`

## 5. 对单个模型做三维可视化验证

作用：
- 显示 STEP 模型
- 用红色球标出预测为正例的孔洞候选

注意：
- 需要带 `pythonocc` 的 Python 环境
- 建议先激活 `cad_graph_env`

命令：

```powershell
conda activate cad_graph_env
cd D:\Projects\gjy_byproject
python .\python\visualize_hole_candidates.py .\data\dirty_training_set\44.step --detector .\build\Debug\Detector.exe
```

常用调参：

```powershell
python .\python\visualize_hole_candidates.py .\data\dirty_training_set\44.step --detector .\build\Debug\Detector.exe --score-threshold 0.3 --sphere-scale 1.0
```

说明：
- `--score-threshold` 越低，显示出来的候选越多
- `--sphere-scale` 越大，红球越容易看见

## 7. 从头开始时的推荐流程

建议按下面顺序执行：

1. 把训练 STEP 模型放进 `data/dirty_training_set`
2. 生成孔洞候选训练集
3. 训练孔洞模型
4. 对单个模型做文本推理检查
5. 对单个模型做三维可视化验证
6. 逐个模型观察是否漏检、误检

对应命令：

```powershell
cd D:\Projects\gjy_byproject
.\build\Debug\Detector.exe --train-hole
python .\python\train_hole_candidate_gcn.py
python .\python\predict_hole_candidates.py .\data\dirty_training_set\44.step --detector .\build\Debug\Detector.exe
python .\python\visualize_hole_candidates.py .\data\dirty_training_set\44.step --detector .\build\Debug\Detector.exe --score-threshold 0.3 --sphere-scale 1.0
```

## 8. 常见问题

### 8.1 找不到 `python\visualize_hole_candidates.py`

原因：
- 当前目录不在项目根目录

解决：

```powershell
cd D:\Projects\gjy_byproject
```

### 8.2 `ModuleNotFoundError: No module named 'OCC'`

原因：
- 当前 Python 环境没有安装 `pythonocc`

解决：

```powershell
conda activate cad_graph_env
```

### 8.3 打开可视化后看不到红球

常见原因：
- 红球太小
- 红球被实体挡住
- 阈值太高导致显示数量少

建议先试：

```powershell
python .\python\visualize_hole_candidates.py .\data\dirty_training_set\44.step --detector .\build\Debug\Detector.exe --score-threshold 0.3 --sphere-scale 1.0
```
