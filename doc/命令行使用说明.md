# 命令行使用说明

本文档只保留当前仍在使用的主线流程。

建议所有命令都在项目根目录执行：

```powershell
cd D:\projects\gjy_byproject
```

## 1. 导出训练集

作用：
- 遍历 `data/plane_model` 下已经注入并验证过的数据
- 提取 face-level 几何与拓扑特征
- 导出训练所需 CSV

命令：

```powershell
.\build\Debug\Detector.exe --train
```

输出文件：
- `data/wing_rivet_training_set.csv`

## 2. 训练图神经网络

作用：
- 读取训练/验证 CSV
- 按 `graph_id` 组装图数据
- 训练当前使用的 `RivetGNN`
- 当前只使用 `plane_model_face_train.csv` / `plane_model_face_val.csv` 这一对 19/5 分割文件

命令：

```powershell
D:\Anaconda\envs\cad_graph_env\python.exe .\python\train_rivet_gcn.py --csv data\plane_model\plane_model_face_train.csv --val-csv data\plane_model\plane_model_face_val.csv --training-mode window --window-hop 2 --epochs 150 --model-out rivet_gnn_no_centerz_split19_5.pth --stats-out rivet_gnn_no_centerz_split19_5_stats.npz --eval-out rivet_gnn_no_centerz_split19_5_eval.csv
```

输出文件：
- `rivet_gnn_no_centerz_split19_5.pth`
- `rivet_gnn_no_centerz_split19_5_stats.npz`
- `rivet_gnn_no_centerz_split19_5_eval.csv`

## 3. 导出单模型推理数据

作用：
- 对单个 STEP 模型提取推理特征
- 生成推理阶段使用的 CSV

命令：

```powershell
.\build\Debug\Detector.exe --predict .\data\plane_model\step\109-ww1-standart-e-1-aircraft CATIA STP_standart-e1_wing_rivets.step
```

输出文件：
- `data/current_inference.csv`

## 4. 可视化 GNN 预测结果

作用：
- 调用 `Detector.exe --predict`
- 加载训练好的模型做推理
- 按面标签对 STEP 模型着色显示

命令：

```powershell
D:\Anaconda\envs\cad_graph_env\python.exe .\python\visualize_rivets.py .\data\plane_model\step\109-ww1-standart-e-1-aircraft CATIA STP_standart-e1_wing_rivets.step --detector .\build\Debug\Detector.exe --compare-labels .\data\plane_model\label\109-ww1-standart-e-1-aircraft CATIA STP_standart-e1_wing_rivets.labels.json --model .\rivet_gnn_no_centerz_split19_5.pth --stats .\rivet_gnn_no_centerz_split19_5_stats.npz --inference-mode window --window-hop 2
```

无界面仅导出预测：

```powershell
D:\Anaconda\envs\cad_graph_env\python.exe .\python\visualize_rivets.py .\data\plane_model\step\4-20 xi-an y20 STP STL_Xian Y-20 v3_wing_rivets.step --detector .\build\Debug\Detector.exe --compare-labels .\data\plane_model\label\4-20 xi-an y20 STP STL_Xian Y-20 v3_wing_rivets.labels.json --model .\rivet_gnn_no_centerz_split19_5.pth --stats .\rivet_gnn_no_centerz_split19_5_stats.npz --inference-mode window --window-hop 2 --no-display --pred-out .\scratch\4-20_split19_5_predictions.csv
```

## 5. 注入与数据集验证

单模型注入：

```powershell
.\build\Debug\Detector.exe --inject-wing-rivets .\data\plane_model\source\4-20 xi-an y20 STP STL_Xian Y-20 v3.step
```

批量注入：

```powershell
.\build\Debug\Detector.exe --inject-wing-rivets-batch .\data\plane_model\source
```

验证数据集：

```powershell
.\build\Debug\Detector.exe --validate-wing-rivet-dataset .\data\plane_model
```

## 6. 推荐流程

建议按下面顺序执行：

1. 先完成 `data/plane_model/source` 的注入
2. 运行 `--validate-wing-rivet-dataset`
3. 运行 `--train` 导出总 CSV
4. 切分出显式 `train/val` CSV
5. 运行 `train_rivet_gcn.py` 训练模型
6. 用 `--predict` 或 `visualize_rivets.py` 做单模型验证

## 7. 常见问题

### 7.1 找不到 `python\visualize_rivets.py`

先确认当前目录在项目根目录：

```powershell
cd D:\projects\gjy_byproject
```

### 7.2 `ModuleNotFoundError: No module named 'OCC'`

说明当前 Python 环境没有 `pythonocc`，先切到可视化环境：

```powershell
conda activate cad_graph_env
```

### 7.3 推理 CSV 缺少 `graph_id` 或 `model_name`

通常说明用的是旧 CSV，重新执行一次：

```powershell
.\build\Debug\Detector.exe --predict .\data\plane_model\step\109-ww1-standart-e-1-aircraft CATIA STP_standart-e1_wing_rivets.step
```
