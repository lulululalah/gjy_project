## 0. 一句话定位

> **一个「注入即真值」的自监督 B-Rep 微小特征去除框架：通过程序化注入在干净 CAD 上
> 自动合成「去除前/后成对模型 + 逐面/逐实例/逐操作标签」，训练局部窗口多任务 GNN 来
> 识别并开出「去除处方」，用 CAD 内核执行去除，并以「注入的逆操作」为真值做闭环验证，
> 最终以网格/仿真加速比衡量价值。**

这条线正好是两份调研都判定为「最有发表潜力」的**混合式、任务驱动、闭环验证** pipeline，
且直击它们共同点名的 **#1 数据缺口：缺少成对的去除前/后真值**。

## 1. 研究脉络（领域故事线 → 我们的切入）

调研把近五年工作分成三条线：

1. **Mesh 侧简化**（CVPR/SIGGRAPH）：Neural Mesh Simplification、特征保持 decimation、
   NASM 等 —— 强于「保细节去冗余」，但**无精确 B-Rep 合法性、无特征语义**。
2. **CAD/B-Rep 侧 defeaturing**（CAD/JCISE/IJNME）：blend-chain suppression、体积分解、
   多目标特征简化、analysis-aware defeaturing —— 强于「按语义删、保实体合法」，但
   **规则依赖强、代码/基准稀缺、跨特征族泛化弱**。
3. **B-Rep 原生学习**（UV-Net→BRepNet→Hierarchical CADNet→AAGNet→BRepFormer→
   BRepMAE/FeatureFox）：是最强的**识别前端**，但**本身不做去除、不保证几何合法**。

**两条裂缝**（两份调研反复强调）：
- 识别 ≫ 去除：「识别」数据/方法远多于「去除并验证」；
- 缺成对真值：几乎没有「删前模型—删后 GT—下游(网格/CAE)后果」三元组。

**我们的切入**：用「程序化注入」一举把第 3 条（学习识别）与第 2 条（几何去除）接起来，
并**自动制造**出缺失的成对真值，从而把整条「识别→去除→验证」闭环跑通。

## 2. 当前痛点（Problem Statement）

| # | 痛点（来自调研 + 本项目实测） | 我们如何回应 |
|---|---|---|
| P1 | **缺成对去除前/后真值**，模型只能学到「形状去噪」而非「特征重要性」 | 程序化注入：注入前=干净 GT，注入后=输入，逆操作=去除 GT，逐面/实例/操作标签精确 |
| P2 | **识别与去除脱节**：多数工作停在识别准确率，报不出「删错的代价」 | 闭环：GNN 处方 → 内核执行 → 恢复误差(Hausdorff/体积) + 网格/仿真后果 |
| P3 | **真实工业 B-Rep 上几何手术不鲁棒**（曲面 NURBS + 裁剪 + 开壳 + 多部件） | 本项目实测验证了这一痛点（布尔/压印在 747 上失败）；论文把它作为**鲁棒性研究**正式刻画 |
| P4 | **并非所有小特征都该删**（任务相关：结构 vs 流体 vs 设计） | 操作头 + 可扩展的 task/analysis-aware 评分（与 analysis-aware defeaturing 对接） |
| P5 | **合成→真实 domain gap** | 局部窗口（k-hop）带来平移不变与强泛化；可叠加自监督预训练（对标 BRepMAE） |

## 3. 核心贡献（Contributions）

> 标注 ✅ 已实现 / ◐ 部分 / ○ 待补，便于评估论文「可写」与「需补实验」的边界。

1. **C1 注入即真值的成对数据合成框架**（直击 P1）✅(简单/Y-20) ◐(复杂件)
   程序化在干净 CAD 上注入微小特征（铆钉/孔/凸起三型…），用布尔历史(BOP)精确记录
   「哪些面属于哪个特征实例、对应什么去除操作」，**同时得到去除前后成对模型**。
   *与调研对比*：填补 ABC/Fusion360/MFCAD++ 都没有的「成对 + 去除操作」标签。

2. **C2 局部窗口多任务 B-Rep GNN**（语义 + 实例 + 操作）✅
   面图上共享 NNConv 编码器 + 三头：逐面语义、逐边「同实例」亲和度（连通分量→实例）、
   逐面去除操作。k-hop 子图窗口提供平移不变与可扩展。
   *与调研对比*：把 AAGNet 式「语义+实例+底面」升级为「语义+实例+**去除操作处方**」，
   直接面向去除而非仅识别。

3. **C3 识别→去除→验证闭环**（直击 P2）◐
   GNN 处方按实例+操作分组 → CAD 内核执行删除补平 → `BRepCheck` + 体积阈值门控 +
   **恢复误差**（与注入前 GT 比 Hausdorff/体积）+ 网格/仿真后果。
   *与调研对比*：把「analysis-aware defeaturing 的误差思想」工程化为可跑的闭环系统。

4. **C4 真实工业件上的几何手术鲁棒性分析与基准**（直击 P3）◐
   系统比较布尔融合 vs 参数域压印(`BRepFeat_SplitShape`)在 平面/曲面/裁剪/开壳/多部件
   上的成功率与失效模式，给出「何时可靠、为何失败、如何回退保全」的工程结论。
   *与调研对比*：调研指出「local geometric surgery 是最缺、最有价值的部分」，本贡献正面攻它。

5. **C5 去特征 benchmark + 下游评测协议**（直击 P1/P2）○
   公开「合成成对集 + 四层指标（识别/几何/网格/仿真）」，补调研点名的 benchmark 空白。

> **最稳的论文核心 = C1 + C2 + C3**（数据 + 方法 + 闭环），C4 是差异化亮点，C5 是「数据
> 集/benchmark」型加分项。即便复杂件几何手术暂不完美，C4 的「鲁棒性分析」本身即贡献。

## 5. 实验设计（采用两份调研建议的「三层数据 + 四类指标」）

**三层数据**
1. 公开识别集做识别能力对照：MFCAD++ / MFInstSeg / CBF。
2. 通用 CAD 的任务化子集（从 ABC / Fusion360 Segmentation 筛 fillet/hole/chamfer）建近似 GT。
3. **自建合成成对 CAE benchmark**：结构 + 流体各至少一个算例，给「删前后网格/单元数/
   求解时间/QoI 偏差」。
4. 真实工业件（如 747/Y-20）：做 C4 鲁棒性分析。

**四类指标**（缺一不可，否则像 heuristic）
- 识别：face IoU / instance F1 / PQ / 操作准确率。
- 几何：双向 Hausdorff / 体积差 / 被删特征数与类型 / **恢复误差**。
- 网格：单元数、最大 skewness、orthogonal quality、无效单元率。
- 仿真：wall-clock、自由度、迭代次数、QoI(应力峰值/压降/升阻)偏差。

**关键消融**（调研强调比「换 backbone」更有价值）：去窗口/去拓扑边特征/去操作头/
去恢复误差门控/删除顺序/结构 vs 流体共用优先级是否失效/是否需自监督预训练。

## 6. 与「代码现状」的差距（写论文前需补）

- ○ **真实注入数据端到端训练 GNN**（目前只在合成图验证，指标近满分=可分性导致，非真实难度）。
- ◐ **复杂件几何去除鲁棒**（曲面 NURBS 压印/布尔失败 → 需标定容差/UV尺度/回退策略）。
- ○ **网格/仿真闭环（M7）**：需接一条仿真工具链 + 定义 QoI 与容差。
- ○ **task/analysis-aware 评分**（P4）：操作头之上叠加误差驱动的重要性排序。

## 7. 相关工作一句话定位（投稿时的「我们 vs 他们」）

- vs **mesh 简化（NMS/NASM/CVPR'25）**：他们去冗余不保 B-Rep 语义/合法；我们在精确
  B-Rep 上按特征语义去除并保合法。
- vs **CAD defeaturing（blend chain/体积分解/多目标）**：他们靠规则；我们用学习前端
  泛化到交叠/复杂特征，规则只作执行器。
- vs **B-Rep 学习（AAGNet/BRepFormer/FeatureFox）**：他们止于识别；我们出**去除处方 +
  闭环验证**，并提供成对去除真值。
- vs **analysis-aware defeaturing（IJNME/CAD'24）**：他们重数学误差控制（多为 2D/IGA）；
  我们做 3D 工业件上可跑的「学习识别 + 内核执行 + 误差验证」系统。
