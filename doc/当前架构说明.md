# 当前架构说明

## 1. 当前主线

项目当前采用纯图方法，训练监督已经统一到注入生成的 `labels.json`。

主链路是：

`STEP -> 注入/导出 labels.json -> FaceFeature -> Face Graph -> GNN -> Face Label / Visualization`

这里的关键判断是：
- 不再用启发式规则作为默认训练监督
- 单面几何特征和邻接拓扑共同进入图
- 最终识别交给 GNN，而不是先做手工 candidate 筛选

## 3. 数据流

训练阶段：
1. `Detector.exe --train`
2. 生成 `data/wing_rivet_training_set.csv`
3. 从最新主数据集切分出当前使用的 19/5 文件：
   `data/plane_model/plane_model_face_train.csv`
   `data/plane_model/plane_model_face_val.csv`
4. `python .\python\train_rivet_gcn.py`
5. 输出模型与归一化统计

推理阶段：
1. `Detector.exe --predict <file>`
2. 生成 `data/current_inference.csv`
3. `python .\python\visualize_rivets.py <file> --compare-labels <labels.json>`
4. 输出面标签并完成可视化

## 4. 当前默认模型

当前仓库默认使用：
- `rivet_gnn_no_centerz_split19_5.pth`
- `rivet_gnn_no_centerz_split19_5_stats.npz`

这版模型对应：
- 训练集 `19` 个模型
- 验证集 `5` 个模型
- 不使用 `centerZ/nx/ny/nz` 绝对姿态特征
- 使用 `normalNeighborDotMean/Min/Max` 相对邻面法向特征
