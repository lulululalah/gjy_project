## Face 邻域特征

为了解决大面积普通面被误判为铆钉的问题，新增了 face 级邻域统计特征。

新增邻居面积相关特征：

- `neighborAreaMean`
- `neighborAreaMax`
- `areaToNeighborMean`
- `areaToNeighborMax`

新增邻居面类型统计：

- `neighborPlaneCount`
- `neighborCylinderCount`
- `neighborCurvedCount`

新增边类型统计：

- `convexEdgeCount`
- `concaveEdgeCount`
- `smoothEdgeCount`
- `convexEdgeRatio`
- `concaveEdgeRatio`

这些特征用于让模型学习当前 face 周围的局部结构，而不只依赖当前 face 自身几何属性。

## Edge 特征

进一步将部分逐连接关系放到 GNN 的 edge 属性中。

原来 edge 上只有：

- `edge_types`

现在 edge 上包含 4 维属性：

- `edge_types`
- `edge_area_ratios`
- `edge_neighbor_surface_types`
- `shared_edge_lengths`

含义：

- `edge_types` 表示当前 face 与邻居 face 的凸、凹或平滑关系。
- `edge_area_ratios` 表示当前 face 面积与邻居 face 面积的比例。
- `edge_neighbor_surface_types` 表示邻居 face 的 surface type。
- `shared_edge_lengths` 表示两个 face 的共享边长度。

Python 构图逻辑已从 1 维 `edge_attr` 改为多维 `edge_attr`，并且模型初始化时自动读取 edge 特征维度，不再写死 `edge_features=1`。

## 特征归一化

- node 特征继续使用训练集均值和方差归一化。
- edge 特征也新增均值和方差归一化。
- `rivet_gnn_stats.npz` 现在保存：
  - `feature_cols`
  - `edge_attr_cols`
  - `mean`
  - `std`
  - `edge_mean`
  - `edge_std`

这样训练和推理时使用一致的 node/edge 特征尺度。

## 模型训练结果

### 加入 face 邻域特征后

验证结果：

- 铆钉类 precision：0.5288
- 铆钉类 recall：1.0000
- 铆钉类 f1：0.6918
- mIoU：0.7599

相较旧模型，误检明显下降，召回保持 1.0。

### 加入 edge 特征并重新训练后

验证结果：

- 铆钉类 precision：0.6587
- 铆钉类 recall：1.0000
- 铆钉类 f1：0.7942
- mIoU：0.8267

对比 face 邻域特征版本：

- precision：0.5288 -> 0.6587
- recall：1.0000 -> 1.0000
- f1：0.6918 -> 0.7942
- mIoU：0.7599 -> 0.8267

说明 edge 特征进一步降低了误检，同时没有增加漏检。

## Cessna 可视化对比

模型：

- `221-cessna-model-grand-caravan STP_cessn CARAVAN v13`

结果变化：

- 旧模型：`TP=18, FP=111, FN=0`
- 加 face 邻域特征后：`TP=18, FP=34, FN=0`
- 加 edge 特征后：`TP=18, FP=28, FN=0`

结论：

- 真实铆钉全部识别，没有漏检。
- 误检从 111 降到 28。
- 大面积误检基本解决，剩余误检主要是小面局部结构相似问题。
