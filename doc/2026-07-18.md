# 2026-07-18：五角星贴花数据扩展

## 本日修改

- 在铆钉注入后的 STEP 模型上新增零厚度五角星贴花：边界将宿主光滑曲面切分，不增加凸起。
- 新增 `decal` 正类标签；训练标签导出将 `rivet` 和 `decal` 都作为“小特征”正样本。
- 新命令：

  ```powershell
  .\build\Debug\Detector.exe --inject-star-decals <after-rivet模型.step> --host-face <面ID>
  ```

  输入限定为 `data/plane_model/after_rivet` 内的 `*_wing_rivets.step`；结果 STEP 与标签 JSON 写入 `data/plane_model/after_two`。

- 新增 [python/select_decal_face.py](../python/select_decal_face.py)：单面聚焦显示候选机身/尾翼面，用菜单 `Candidate > previous/next candidate` 浏览；用户报出 `Fxxx` 后再由 Codex 执行生成。
- 贴花候选仅保留归属于实体的光滑 B 样条、圆柱或平面；自动模式每个模型最多一个贴花。手动 `--host-face` 模式会严格使用指定面。
- 五角星首选外接半径为曲面参数域短边的 `0.44`；这是相对上一版半径 `0.22` 翻倍，即面积扩大 4 倍。若无法放入修剪区域才逐级缩小。
