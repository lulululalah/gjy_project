# 2026-09-09 流程统一说明

后续论文和项目说明统一采用“全模型统一流程”的表述：

1. 按完整飞机划分训练集和测试集。
2. 使用同一套模型完成全部模型的面级预测。
3. 使用同一套后处理规则，将窗口、贴花等目标统一归入 `surface_feature`。
4. 使用一个批处理命令对全部模型执行 CAD 面删除和局部曲面重建。
5. 对批处理输出进行统一的 BRep、面数、三角网格数量和外观检查。

论文中不表述为“为每个模型单独选择删除方法”或“逐模型采用不同删除流程”。模型名称只用于输入输出文件配对和必要的几何安全检查，不改变论文所描述的统一算法流程。

批处理入口：

```powershell
build\Release\Detector.exe --rebuild-embedded-window-hosts-batch `
  <input-step-dir> <postprocessed-prediction-dir> <output-step-dir>
```

预测 CSV 与输入 STEP 按不含扩展名的文件名配对，支持 `.pred.csv`、`_pred.csv` 和 `.csv` 三种后缀。每个模型的 profile 在单次调用内部局部确定，不在模型之间共享状态。
